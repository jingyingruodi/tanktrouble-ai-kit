# TankTrouble AI 文档中心

> 基于 **Chrome DevTools Protocol (CDP)**（远程调试协议）直接驱动 Edge 浏览器，
> 对官方 TankTrouble 游戏做自动化控制与数据采集。无需 Tampermonkey、无需 Selenium/Playwright。

---

## 双 AI 分工

本项目由两个 AI 协作推进，各司其职：

| 角色 | 负责方向 | 相关文档 |
|------|---------|---------|
| **AI-A（游戏接口）** | CDP 自动化、坦克控制、状态查询、弹道火控、监控室、数据采集录制 | `01` `02` `03` `04` `05` `06` |
| **AI-B（模型训练）** | 强化学习环境、PPO/自对弈、训练循环、奖励塑形 | **从 [09-AI-B上游契约](09-AI-B上游契约.md) 开始**（观测/动作/录制/step 契约已就绪） |

> 接口上游（游戏 → 数据）由 AI-A 保障；下游（数据 → 模型 → 动作）由 AI-B 负责。
