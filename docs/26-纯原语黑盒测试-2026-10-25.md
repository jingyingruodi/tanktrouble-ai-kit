# 26 · 纯原语黑盒测试：AI 自己写火控（临时剥离成熟封装）

> 目的：验证**底层原语接口是否足以让"游戏专用 AI"自己实现火控**，而不是让 AI 调用我们封装好的
> 扫角/选角/提前量/转向/寻路。这是训练接口（obs/action/step）验收的核心问题。
> 方法：临时把这些成熟封装**从黑盒包里剥离**，只给原语；子智能体拿不到项目源码，只能读接口文档。

## 2. 轮 1（v1 原语）结果

交付：`tt_bb_lowlevel/agent_ai.py`（1488 行，只 import ttprim + 标准库，未改原语）。

**子智能体自报（60s）**：
```
duration_s=59.2  scans=53  shots=5 (direct=5 bounce=0)
confirmed_hits=5 misses=0  [kills_me=5 victories_me=5 kills_opp=0 victories_opp=0]
self_damage=0  errors=0  rounds_seen=6  inputs: own=670 other=0
```
另一轮 60s：5 发 5 中，其中 4 发是 1 次反弹弹。

**Lead 独立审计**（`scripts/prim_audit.py`，不改子智能体代码，记录每次 `set_input` 的 pid）：
```
44s：shots=4 hits=4 selfdmg=0 err=0  inputs: own=482 other=0
```

结论：**只给原语，AI 能自己写出可用的火控**（静态靶 5/5、0 自伤、0 误控）。
但更重要的是它挖出的**接口缺口**（13 条），这些才是训练接口要补的。

### 2.1 缺口分类

| 类别 | 缺口 |
|---|---|
| **真·原语缺陷（已修）** | ① `projectile_path` 从车体中心起算 → 当前朝向附近 121 个角度"零反弹命中自己"假阳性；② 回合阶段/roundId 缺失（`active` 恒 False 等）；③ 无输入回读/武器状态；④ 无墙厚/几何文档；⑤ 无批量弹道（1440 角≈1s）；⑥ 角度约定未明说 |
| **已补/已文档化** | ⑦ 炮口偏移/弹丸半径/坦克尺寸常量；⑧ projectiles 字段 schema；⑨ 比分语义（击杀 vs 自杀）、非原子；⑩ 转向量化实测（4.775°/帧、残差 ~2.4°）；⑪ 开火边沿触发/冷却 |
| **物理/游戏限制（不能补）** | ⑫ 无 seed/地图 id（游戏不提供，可从 walls 自建签名）；⑬ 无游戏帧号/simTime、无原子事件流 |
| **行为层（属 AI 策略）** | 移动目标提前量、切位/埋伏策略 —— 不是接口问题 |

### 4.1 轮 2 发现的新缺口（v1 未覆盖）

| # | 缺口 | 影响 | v3 修复 |
|---|---|---|---|
| a | 官方弹道**零宽**、无 radius 参数 | 反弹路径无法评估半径效应：实测 2 反弹 45.6m"验证命中"实际打偏后反弹回来**把自己打死**；1 反弹 50.7m 假阳性反复打偏 | ✅ 新增 `simulate_shot(radius=0.25)`（自写近似仿真，墙 AABB + 坦克 OBB 膨胀，逐段 `deadly` 标记） |
| b | 只能从**当前真实位置**推演 | 无法评估"站到拐角能否打"，选位只能开过去再扫（每回合多 2–7s） | ✅ `projectile_path(s)` 支持 `from_xy=(x,y)` |
| c | 路径无**致命段/首反弹标记** | 自伤检查只能整条路径保守处理，误杀安全反弹解 | ✅ 返回 `first_bounce_index/deadly_from_index`；simulate 逐点 `bounce/deadly` |
| d | 打偏后的**续飞轨迹不可见** | 无法评估冒险反弹解 | ✅ `ignore_tanks=True`（只算墙）+ `simulate_shot(ignore_tanks=...)` |
| e | `weapon_state` 语义不明、无弹速/寿命/半径 | 换武器就错 | ✅ `weapon_info()`（type/name/speed/lifetime/range/radius/ammo） |
| f | 无输入生效帧号/simTime | 转向只能脉冲+回读 | ⚠️ 仅有 `t_ms` 墙钟；游戏未暴露帧号（**仍未解决**） |
| g | `hitTank` 可为自己 / `end` 可能 None | 文档缺失易误用 | ✅ 文档明确；`end` 保证非空 |
| h | 换场瞬态（roundId 变后 ~20–90ms 场景未稳定） | +20ms 扫到的窗 +90ms 消失 | ✅ `round_age_ms(st)` 判断稳定期 |
| i | 无"炮口是否在墙内"原语 | 依赖自写矩形判断 | ✅ `point_blocked()` |
| j | `walls` 有重复段、`input_state` 结构不一致、`countdown` 陈旧 | 轻微 | ✅ `walls_unique()`；`input_state(pid)`/`input_state()` 均返回按 pid 键的 dict；`countdown` 语义写入文档 |

**轮 2 核心结论**：v2 的批量弹道（360 角 5–10ms）是高频扫描的关键；
但"零宽射线"让**安全反弹火控不可行**，AI 只能退化成只打直线（发射机会变少）。

## 4.6 轮 4（v4 原语）结果

交付：`tt_bb_lowlevel4/agent_ai.py`（只 import ttprim + 标准库，未改原语）。

**子智能体自报（60s）**：
```
scans=99 scan_directions=7524 simulate_shots=9367 candidates_found=366
fires=5 fire_failures=0 hits=5 hit_rate=100% self_hits=0 deaths_by_foe=0
errors=0 rounds_seen=6 controls_by_pid={'22841415': {...}}   # 只有自己
shots: bounces=2/3/4/5/3，traveled=52/64/63/78/54m，全部 hit
```
**Lead 独立审计**：`fires=5, violations={}, kills=5, opp_victories=0`（0 自伤）。

**关键**：5 发全部是 **2–5 次反弹解**——这是 v4 `from_rot`（扫角时假设车体朝向）
+ `max_bounces` 修正 + 双引擎复核共同作用的直接证据。子智能体对 v4 的逐条评估：

- `from_rot`：1216 个对照方向里 **33 个（2.71%）判定翻转**，其中 22 个是
  "旧车体以为安全、对齐后其实会自伤"的**危险假阴性** → 修正真实必要；
  但它不是命中率银弹（需配合连续瞄准窗口 + 转后复验 + 一次一发）。
- `max_bounces`：N=0/1/2 实测官方与 sim 都恰好 0/1/2 次墙反弹，**off-by-one 已修好**。
- `complete/truncated`：**不足以**识别"打偏后飞回来打自己"（N=8→16 多暴露 6–11 个自伤方向）；
  正确配方是 `ignore_tanks=[foe]` 保留自己 + N=16 + `from_rot` 对齐 + 检查 `hitTank==me`。
- `muzzle_blocked`：检测真实可用（8/76 方向触发），但**只报告不阻止**，调用方必须自己拒绝；
  按 0.25m 弹径判定，比"炮口点在墙内"更保守。
- 其他：`_bulletCount` 恒为 5（不是剩余弹药）；`simulate_shot` 的 `max_length` 是软的
  （180 仍给 205.6m）；官方 `projectile_path` 无 `from_rot`；`state()` 无 `round_seen_age_ms`；
  官方零宽 vs 半径 sim 常分歧（多反弹掠射都不能盲信）。
- 受控自伤实验（主动测试、不属于 agent 行为）：1 反弹 4.4m 飞回真把自己打死，
  `vict_foe` +1、`kill_foe` 不变，约 3.1s 后到账，验证了 README 自伤语义。

## 4.7 v5 原语（已实现，一致性 PASS）

`tt_bb_lowlevel5/ttprim` 针对轮 4 缺口：
- `simulate_shot(max_length=...)` 改为**硬限制**（路径不超过该距离，且 ≤180m 寿命），
  新增 `truncation_reason`（tank/wall/bounces/length/muzzle）、`max_length_applied`、`angle`；
- `from_pose=(x,y,rot)` 假设**车体位姿**（炮口与自车 OBB 都按假设位姿）；
  `from_xy` 文档明确为**起点**；
- `origin_blocked_point`（r=0 炮口点）与 `origin_blocked`（按弹径保守）分开返回；
- `simulate_shots(from_rots=[...])` 支持每个候选不同车体朝向；
- `state()` 直接带 `round_seen_age_ms/round_age_ms`；
- `weapon_info` 修正为 `ammo_capacity/bullets_fired`（`ammo_left=None`，容量不递减）；
- README 增加"打偏自伤检查配方"（`ignore_tanks=[foe]` + N=16 + `from_rot` + 检查 `hitTank==me`）。

## 5. 对训练接口的直接结论

1. **原语是够的**：只给 state + set_input + 官方弹道 + 几何查询，AI 就能写出 5/5 命中、
   0 自伤、0 误控的火控；不需要我们封装扫角/选角。
2. 对**模型训练接口**，以下原语必须原样保留并稳定：
   - `state()`（含 phase/roundId/t_ms/tanks vx,vy/projectiles schema/walls）；
   - `set_input`（5 布尔，立即生效不自动释放）+ `input_state()` 回读；
   - `projectile_path(s)`（炮口起算 + 批量）；
   - `accepts_input()`、`weapon_state()`；
   - 物理常量表（弹速/寿命/范围、坦克尺寸/速度、炮口偏移、弹丸半径、墙厚、转向量化）。
3. 训练侧仍需补的（接口外/行为外）：
   - **原子事件流**（killer/victim/cause）替代比分轮询；
   - **game tick / simTime** 或固定步长封装（当前只有 `t_ms` 墙钟）；
   - **seed/map id**（可从 walls 签名近似）；
   - 移动目标提前量属行为层（模型可学），不必进原语。
