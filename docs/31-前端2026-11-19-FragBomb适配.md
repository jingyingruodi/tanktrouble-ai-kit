## 2. kit 适配内容

- `kit/ttkit`：
  - `WEAPON_NAMES[6] = FRAG_BOMB`
  - 新增 `PROJECTILE_NAMES`（6=Frag Bomb 母弹，7=破片）
  - `MUZZLE_OFFSET[6]=2.25`、`WEAPON_SPEED[6]=18`、`WEAPON_RANGE[6]=126`
    （126 = 7s × 18m/s 的理论上限；实际遇敌会提前爆炸）
- `cdp_tools/official_ballistics.py`：
  - 新增 `WEAPONS['frag_bomb']`：速度/寿命/炮口/单发/爆炸延迟/30 破片常量；
  - 明确标注：只推演母弹直线段，**不包含爆炸范围与 30 破片碰撞判定**。
- `monitor_server.py`：
  - `MAXLIFE[6] = C_FRAG_BOMB_MAX_LIFETIME`；
  - projectile 输出新增 `typeName`，区分 `FRAG_BOMB` 与 `FRAG_BOMB_SHRAPNEL`；
  - 破片 type=7 没有独立寿命常量，没有硬编码猜测值。
- `kit/README.md`：补充 Frag Bomb / 破片类型说明。
- 新增 `scripts/measure_frag_bomb.py`：本地发放 Frag Bomb 并采样母弹/破片。

## 4. 边界

- `official_ballistics/scan` 只处理母弹的镜面直线；**爆炸范围、30 破片、破片碰撞**未建模；
- `ammo()` 对 Frag Bomb 不适用（它是单发制，没有普通 bulletCount 字段）；
- 本地发放是测试操作，不是自然 crate 拾取；不能直接当自然对局 DPS；
- 新武器会改变 P2/P3 的威胁模型：L0 需要爆炸/破片 hazard，不能继续用单发子弹模型。
